# TCV Food Bank Website Redesign

A front-end redesign mockup for the TCV Food Bank + Mobile Pantry website, built during a summer research co-op to improve UX, accessibility, and mobile responsiveness on the organization's real public site.

## Highlights

- Semantic, accessible markup: ARIA labels and roles on navigation, a screen-reader-only page heading, `aria-expanded`/`aria-controls` on the mobile menu toggle
- Responsive hamburger navigation with an overlay for small screens
- Sections for the food bank's core services: home, getting food, the mobile pantry schedule, volunteering, and about
- Clean typography via Google Fonts (Inter) and Tabler Icons for lightweight, accessible iconography
- Direct integration with the organization's real donation page

## Tech

HTML5, CSS3

## Status

Static homepage mockup, built as a design/UX proposal for the live tcvfoodbank.org site.
